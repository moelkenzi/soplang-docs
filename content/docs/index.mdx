## <span className="text-sm">The First-Somali Programming Language</span>


Soplang <span className='text-fd-muted-foreground text-sm'>(Somali Programming Language)</span> is an interpreted programming language that uniquely combines static and dynamic typing systems with syntax based on the Somali language. It is designed to lower the barrier to entry for Somali speakers learning to program while maintaining modern language features and paradigms.
